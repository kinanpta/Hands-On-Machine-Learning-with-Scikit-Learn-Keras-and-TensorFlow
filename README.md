This repository contains a complete reproduction, structured summary, and
theoretical deep-dive of the book:

**Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow**  
by *Aurélien Géron (O’Reilly)*

The project is developed as part of the **Machine Learning and Deep
Learning** course at **Telkom University**, and is designed to strengthen
both conceptual understanding and practical skills in modern machine
learning systems.

---

## 📘 Project Overview

The purpose of this repository is to provide a comprehensive learning
resource that combines theoretical explanations with hands-on
implementations. Each chapter from the book is carefully summarized,
explained, and implemented using Jupyter Notebooks.

The content is organized to follow the structure of the original book,
starting from fundamental machine learning concepts and progressing toward
advanced deep learning topics and real-world deployment strategies.

---

## 📂 Contents

Each chapter is documented in its own Jupyter Notebook and includes:

- A concise chapter summary  
- In-depth theoretical explanation  
- Reproduced code examples and experiments  
- Detailed code explanation  
- Discussion and conclusion  

The full learning progression includes:

- Machine Learning foundations and workflows  
- Model training, evaluation, and optimization  
- Feature engineering and data preprocessing  
- Deep neural networks and training strategies  
- Convolutional Neural Networks for computer vision  
- Sequence modeling and Natural Language Processing  
- Representation learning and generative models  
- Reinforcement learning  
- Scalable training and deployment of ML systems
